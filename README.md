# 🧬 DevDNA

> Understand your developer identity through your GitHub activity.

DevDNA is a developer intelligence platform that analyzes a developer's GitHub profile, repositories, programming languages, technologies, project activity, collaboration patterns, and development history to generate meaningful insights about their technical profile.

Instead of simply displaying GitHub statistics, DevDNA transforms raw GitHub data into a structured developer profile containing strengths, weaknesses, skill scores, technology recommendations, project insights, and career-oriented information.

---

## 🚀 Overview

GitHub contains a huge amount of information about how a developer learns, builds, experiments, collaborates, and grows.

However, raw GitHub statistics don't always provide a clear picture of a developer's actual profile.

DevDNA attempts to answer questions such as:

- What technologies does a developer work with?
- What are their strongest technical areas?
- Which areas appear weaker?
- How diverse is their technical experience?
- How active are their projects?
- How much of their work is original versus forked?
- How frequently do they collaborate?
- What technologies could they learn next?
- Which developer roles best align with their current skill profile?
- How strong is their overall GitHub portfolio?

DevDNA takes this raw information and converts it into an understandable developer intelligence report.

---

# ✨ Features

## 👤 GitHub Profile Analysis

DevDNA retrieves and analyzes GitHub profile information to build a technical overview of the developer.

The analysis includes information such as:

- GitHub profile information
- Repository statistics
- Programming language usage
- Project activity
- Repository ownership
- Collaboration patterns
- Repository popularity
- Technical skills

---

## 📊 Repository Analytics

DevDNA analyzes a developer's repositories to understand their development patterns.

It currently evaluates metrics such as:

- Total repositories
- Original repositories
- Forked repositories
- Average repository stars
- Repositories with descriptions
- Solo projects
- Collaborative projects
- Active projects
- Inactive projects
- Popular projects

This helps transform raw repository data into meaningful portfolio-level insights.

---

## 💻 Technology & Language Analysis

DevDNA analyzes the programming languages and technologies used across repositories.

The system identifies:

- Programming languages
- Technology categories
- Known technologies
- Technology distribution
- Technology strengths
- Technologies that could be explored next

Language usage is also converted into percentage-based distributions to make the developer's technical focus easier to understand.

---

## 🧠 Developer Skill Scoring

DevDNA calculates role-oriented skill scores based on the developer's GitHub activity and technology usage.

The current system evaluates profiles against predefined developer roles such as:

- Frontend Developer
- Backend Developer
- Full Stack Developer
- Data Scientist
- ML Engineer
- etc.
